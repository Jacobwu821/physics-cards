# 物理卡片（PhysicsCards）

面向个人物理学习的记忆卡片应用：牌组 + 卡片类型 + 标签，Markdown/LaTeX 混排，FSRS 间隔复习，随机抽卡，多设备同步，备份恢复。中文界面，自用，不上架。

## 平台方案（实际支持的）

| 平台 | 使用方式 | 说明 |
|---|---|---|
| Windows / Mac | 浏览器打开同步服务地址；Chrome/Edge 地址栏「安装应用」可当独立窗口 | 编辑、整理为主，宽屏双栏编辑与预览，快捷键 |
| iPhone | Safari 打开同步服务地址 → 分享 → 「添加到主屏幕」 | 复习、快速记录为主；单手底部导航 |

- 代码：React + TypeScript + Vite 的单页应用（PWA 形式）。
- 本地存储：浏览器 IndexedDB（Dexie）。刷新、关闭后数据仍在；未配置同步也可完全离线使用（首次需联网加载页面）。
- 同步：自托管 Node 服务（Express + 内置 `node:sqlite`），单用户令牌。三台设备填写同一地址和令牌即共享卡片与复习进度。
- 图片以二进制存本地，并作为附件同步到服务器。

**你需要自己准备的**：一台长期开着的机器运行同步服务（家里的 Windows/Mac 即可），并保证 iPhone 能访问它。出门用流量时的方案见下一节。

## 出门用流量：推荐部署方式

手机在外面要满足两件事：页面本身能打开（离线应用壳），以及能连到同步服务（公网可达）。

**离线应用壳**：构建产物自带 Service Worker，会把页面、脚本和全部 KaTeX 字体缓存在手机上。之后即使没有网络，从主屏幕打开也能进入应用并正常渲染公式；本地改动会在联网后自动同步。前提是页面通过 **https**（或 localhost）打开，浏览器才允许注册 Service Worker，用 `http://192.168.x.x:8787` 这类局域网地址是不行的。「设置 → 出门使用 / 离线」会显示当前地址是否满足条件、离线缓存是否就绪。

**方案 A（推荐，免费，不暴露公网）：Tailscale + Tailscale Serve**

1. 在运行同步服务的电脑和 iPhone、Mac 上都安装 [Tailscale](https://tailscale.com/)，登录同一账号；三台设备就处在同一个私有网络里，手机用流量也能访问家里电脑。
2. 在运行服务的电脑上执行一次（需先在 Tailscale 管理后台开启 HTTPS 证书，即 MagicDNS + HTTPS）：

   ```bash
   tailscale serve --bg 8787
   ```

   它会给出一个形如 `https://你的电脑名.你的tailnet.ts.net` 的 https 地址，并自动签发证书。
3. 三台设备都用这个 https 地址打开应用，iPhone 上「添加到主屏幕」；「设置 → 同步」里服务器地址也填这个 https 地址。
4. 手机出门时保持 Tailscale 开着即可同步；即使 Tailscale 没开，页面也能离线打开复习，回家或打开 Tailscale 后自动同步。

**方案 B：Cloudflare Tunnel**（有自己域名时）：`cloudflared tunnel` 把本机 8787 映射到 `https://cards.你的域名`，任何网络都能直接访问，无需在手机装客户端；建议在 Cloudflare Access 上再加一层登录保护，因为同步令牌是唯一的凭据。

**方案 C：VPS + Caddy**：把整个仓库部署到一台小型 VPS，Caddy 反向代理到 8787 并自动申请 https 证书。适合不想让家里电脑常开的情况。

三种方案下前端和 API 同源，不涉及跨域和混合内容问题。若你把前端单独放到静态托管（如 GitHub Pages）而 API 在别处，则 API 也必须是 https，否则浏览器会拦截请求。

## 运行方式

要求 Node.js ≥ 22.13（本项目在 Node 24 上开发测试）。

```bash
npm install
npm run build          # 构建前端到 app/dist
npm start              # 启动同步服务（默认 8787 端口，同时托管前端）
```

启动后终端会打印：局域网地址、同步令牌（保存在 `server/data/token.txt`）、数据目录。

- 电脑上打开 `http://localhost:8787`；手机在同一 Wi‑Fi 下打开终端打印的局域网地址，例如 `http://192.168.1.10:8787`。
- 在每台设备的「设置 → 同步」中填写服务器地址与令牌，点「保存设置」。之后会自动同步（启动时、有改动 3 秒后、每 5 分钟、切回窗口时），也可点「立即同步」。
- 可选环境变量：`PORT`、`DATA_DIR`、`SYNC_TOKEN`、`STATIC_DIR`。

开发模式（前端热更新，API 代理到 8787）：

```bash
npm start              # 终端 1：同步服务
npm run dev            # 终端 2：Vite 开发服务器 http://localhost:5173
```

测试：

```bash
npm test               # 前端单元测试（vitest）+ 服务端测试（node:test）
```

Windows 防火墙首次会询问是否允许 node 监听，需要允许「专用网络」，手机才能访问。

## 备份

- 「设置 → 备份与恢复 → 导出备份」得到一个 JSON 文件，包含牌组、卡片（Markdown/LaTeX 源码、格式、标签、来源）、图片（base64）、全部复习记录与调度状态。
- 「导入备份」可选「合并」（按 id 合并，较新的记录胜出）或「替换本设备全部数据」。
- 服务端数据只有 `server/data/` 一个目录，直接复制即为服务器备份。

## 内容格式

正反面都是 Markdown + LaTeX 源码：

- 加粗 `**文字**`、斜体 `*文字*`、下划线 `<u>文字</u>`、列表 `- ` / `1. `、段落空行分隔。
- 行内公式 `$E = \hbar\omega$`，独立公式 `$$ ... $$`（可多行）。
- 图片通过工具栏「图片」按钮插入，源码形式为 `![图片](img://<id>)`。
- 工具栏按钮会在光标处插入分隔符；编辑器下方即时预览，公式错误会列出具体原因，不影响已输入内容。
- 编辑过程中草稿每 0.6 秒自动保存到本地；意外关闭后重新打开会提示恢复或放弃草稿。

## 复习算法

采用 FSRS（Free Spaced Repetition Scheduler，`ts-fsrs` 实现）。选择理由：

- 为每张卡估计记忆稳定性、难度与可提取性，按遗忘曲线安排下次复习，而不是固定日期表；
- 四档评分「忘记 / 困难 / 记得 / 轻松」直接对应 FSRS 的 Again / Hard / Good / Easy；
- 评分前可预览四种评分对应的下次时间；
- 实现独立于界面（`app/src/scheduler/scheduler.ts`），由单元测试覆盖。

参数：目标记忆率 0.9，最长间隔 365 天，学习步骤 1 分钟 → 10 分钟，重学步骤 10 分钟，长间隔带少量随机扰动避免同一天堆积。

状态：新卡 / 学习中 / 复习中 / 重学中。「忘记」进入短间隔重学并记一次遗忘；「轻松」逐步延长间隔。今日队列 = 到期卡（受每日复习目标限制）+ 新卡（受每日新卡上限限制），超出目标的到期卡保留并在完成后可继续开始；错过几天后所有逾期卡保持到期状态，不会被重置。暂停卡不进入队列。

艾宾浩斯遗忘曲线说明了「先密后疏」的原理，但不存在适合每个人的唯一精确时间表，所以间隔由实际评分动态调整。

## 同步与冲突规则

- 牌组、卡片：服务器版本号（rev）乐观并发。本地修改基于旧版本推送时判定冲突：服务器版本成为正本，本地版本另存为一张带「冲突副本」标签的新卡（来源笔记中注明原卡 id），两份修改都不丢。牌组名冲突以服务器为准并提示。
- 复习评分：日志按 id 去重，重复提交不会重复推进计划；调度状态以最后一次评分时间为准（两台设备离线各评一次时，取较晚的一次，两条日志都保留）。撤销通过给日志打「已撤销」标记同步。
- 删除用墓碑标记同步，不物理删除。
- 网络失败时：本地改动保留并标记待推送，界面显示「同步失败」原因，下次自动重试；草稿始终在本地。

## 已完成的功能

- 牌组：创建、重命名、删除（删除时选择「移动卡片到其他牌组」或「同时删除卡片」，后者需输入牌组名确认）。
- 卡片：10 种类型模板（只提供填写引导，不强制），创建、编辑、复制、移动、删除、收藏、暂停；来源信息（书名/论文、页码/章节、链接/DOI、笔记）。
- 卡片库：关键词、牌组、类型、标签、收藏、暂停状态筛选。
- 编辑器：工具栏（加粗/斜体/下划线/列表/行内公式/独立公式/图片）、实时预览、公式错误提示、草稿自动保存与状态显示、Ctrl/⌘+S 保存、桌面双栏。
- 复习：只显示正面，点击卡片或「显示答案」才翻面；点公式/图片/链接/选中文字不翻面；长答案可滚动；翻面后才出现四档评分及预计下次时间；进度与剩余数；撤销最近一次评分并恢复计划；退出后可继续；空格翻面、1–4 评分、Z 撤销、Esc 退出，输入框中不触发。
- 随机抽卡：范围（全部/牌组）、类型、标签、关键词筛选，指定数量，同轮不重复，数量不足明确提示；默认不改复习计划，可主动开启「计入正式复习计划」；暂停卡默认排除，可包含。
- 同步、备份恢复、示例数据（带「示例」标记，可一键移除）、浅色/深色/跟随系统。

## 验证结果

自动化测试（`npm test`）：59 项通过。

- 公式渲染（24 项）：行内/独立公式、分隔符内带空格、下标与星号不被 Markdown 吃掉、中文紧贴公式、多行 aligned、pmatrix、cases、`\bra` `\ket` `\braket`、`\boxed`、`\text{中文}`、列表与加粗内的公式、`\(…\)` `\[…\]` 分隔符、行首 `$$…$$` 后接文字、矩阵行距 `\\[2pt]`、价格式 `$5` 不误判、错误公式给出具体原因、渲染输出的 KaTeX 类名与所加载 CSS 版本一致（曾发现插件自带旧版 KaTeX 导致 `\boxed` 边框塌陷与错误断行，已修复并由此测试守护）。

- 调度：新卡忘记→短间隔、轻松→长期复习；预览与实际评分一致；连续记得间隔递增；忘记→重学且 lapses+1；不同难度不同间隔；撤销恢复；逾期不重置；练习不计入今日量；今日队列的目标限制与超出计数；暂停/删除/牌组过滤；撤销日志不计入上限；跨日期与时区（绝对时间戳到期判断）。
- 随机抽卡：筛选条件、同轮不重复、数量不足差额、随机源可复现。
- 同步合并：拉取决策、卡片冲突生成副本且两份不丢、远端删除+本地修改保留本地、牌组冲突提示、同一日志重复提交只保留一份、两设备各评一次取较晚者、撤销标记覆盖。
- 备份：导出→清空→导入后卡片内容/标签/来源/图片字节/调度状态/日志（含撤销标记）一致；合并导入较新胜出；无效文件被拒绝。
- 服务端：鉴权、版本冲突不覆盖、日志去重与状态 LWW、增量拉取、图片上传下载。

浏览器实测（Windows 11，Claude 内置 Chromium，桌面视口与 375×812 手机视口模拟，浅色与深色）：

1. 创建含中文、加粗、下划线、行内与独立公式、列表、两个标签的卡片，保存后整页刷新再打开：源码逐字一致，可继续编辑。
2. 输入错误公式（未闭合花括号、未定义命令）：给出具体错误，内容不丢；草稿自动保存并在重新打开时提示恢复/放弃。
3. 复习页：初始只有正面；点击公式不翻面；点击卡片翻面后出现四档评分与预计时间（1 分钟 / 6 分钟 / 10 分钟 / 6 天）；评「记得」后卡片按学习步骤回到队尾；撤销后日志标记已撤销、状态恢复为新卡、队列恢复。
4. 随机抽卡：请求 5 张只有 1 张时给出提示；只显示正面；「下一张」不写日志、不改计划。
5. 两个独立浏览器源（localhost 与 127.0.0.1，各自独立的 IndexedDB）模拟两台设备：A 创建卡片 → 同步 → B 拉取 → B 评「轻松」 → A 拉取到完全相同的下次时间与日志；A、B 同时修改同一张卡：B 端得到「冲突副本」新卡与提示，A 端随后也收到该副本；图片在 A 插入后 B 端收到二进制。
6. 手机视口：页面不横向滚动，长公式在卡片内横向滚动，底部导航与评分栏完整；深色模式正常。
7. 公式实测（375px 手机视口，浅色与深色）：一张含 9 个公式的压力卡片（aligned 双行、pmatrix、cases、`\boxed` 分数、`\hat H\ket{n}`、`\(…\)` 分隔符、带 `\text{中文}` 的长行内公式）在编辑预览、卡片库、随机抽卡页均以排版形式显示，无原始 `$` 源码、无 KaTeX 错误；`\boxed` 边框完整、下标正确；长行内公式只在等号等关系符后换行，页面不横向滚动。
8. 离线：在 localhost（安全上下文）注册 Service Worker 并预缓存 65 个文件后，**停止服务器再重新加载**，卡片库页面正常打开，6 个 KaTeX 字体已加载，7 个公式正常渲染；同步状态显示连接失败而不影响使用。新版本发布后打开页面会自动检查并切换到新缓存。
9. 新设备恢复：清空浏览器存储后仅填写同步地址与令牌，牌组、卡片、图片二进制、复习记录全部从服务器拉回。

## 已知限制与未实测项

- **iPhone Safari、Mac 未真机实测**：只做了 375px 视口与触屏 UA 的模拟。「添加到主屏幕」后的表现（安全区、键盘弹出、文件选择、iOS 对长期不用的站点清理存储）需要你在真机确认。
- 离线应用壳要求通过 https（或 localhost）打开；用 `http://192.168.x.x:8787` 打开时不会注册 Service Worker，出门后打不开页面（IndexedDB 中的数据不会丢）。按「出门用流量」一节用 Tailscale Serve 等提供 https 地址即可。
- 出门时同步需要手机能连到同步服务（Tailscale 在线，或服务有公网 https 地址）；连不上时改动保留在本机，联网后自动推送。
- KaTeX 不支持的宏（如 siunitx 的 `\SI`、mhchem 的 `\ce`）会在编辑器中提示「Undefined control sequence」，需改写为 KaTeX 支持的写法。
- 图片同步为「按需下载缺失图片」，未做分块与断点续传；单张图片插入时会缩到最长边 1600px。
- 同步为单用户令牌，没有账号体系；令牌泄露即可读写数据，请只在可信网络（局域网/Tailscale）或 https 下使用。
- 同一张卡在两台设备离线各评一次时取较晚的一次为准，不做两次评分的合并计算。
- 未做：卡片关联、填空卡、图片遮挡卡、复习提醒、薄弱卡专题、从笔记生成卡片（第三阶段候选）。
